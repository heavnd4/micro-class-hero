## 📅 2026-04-27 (底层架构大修、全链路联调成功)

### 1. 核心稳定性修复 (攻坚战)
*   **环境静默崩溃 (失败)**：❌ 发现 Python 3.13 与 `faster-whisper` 的底层库 `ctranslate2` 存在严重兼容性冲突，加载模型即静默退出，无报错日志。
*   **版本回归方案 (成功)**：✅ 彻底卸载 3.13 虚拟环境，重建 Python 3.11 环境。
*   **库匹配补丁 (突破)**：✅ 发现 `ctranslate2` 最新版 (4.7+) 在 Windows 上仍不稳定，精准降级至 **4.6.0**，成功解决模型加载卡点。

### 2. 后端“独立王国”构建
*   **引擎解耦**：✅ 编写 `core_engine.py`，将原本依赖 E 盘外部路径的 AI 逻辑全部封装，实现了自适应模型路径，为容器化部署铺平道路。
*   **依赖缺失 (失败)**：❌ 运行 `app.py` 时遭遇 `ModuleNotFoundError`，发现 `flask`、`opencv-python-headless`、`paddlepaddle` 等 5 个核心库缺失。
*   **自动化补全 (成功)**：✅ 通过自动化脚本扫描并一次性补齐所有 Web 与 AI 运行库，实现了服务器“一键启动”。

### 3. 小程序前端从 0 到 1
*   **框架搭建**：✅ 创建 `miniprogram_frontend` 原生小程序项目，实现 WXML/WXSS/JS 的逻辑闭环。
*   **视觉注入**：✅ 纯代码绘制并注入“音律者 · 琦” (SVG) 虚拟形象，并增加了动态呼吸效果和炼化进度条。
*   **多选逻辑 Bug (修复)**：✅ 原始设计中多选题点击即判定导致无法多选。通过重构交互逻辑，引入“暂存态高亮 + 确认提交”机制，提升了产品的工业感。

### 4. 联调验证成果
*   **全链路闭环**：✅ 在微信开发者工具中，成功跑通了“点击炼化 -> 后端异步转录/出题 -> 前端进度轮询 -> 弹出 AI 题目 -> 答题交互”的完整流程。测试结果符合预期，系统表现稳健。

## 📅 2026-04-25 (项目启动、核心链路攻坚与视觉资产重构)

### 1. 产品定义与 PRD 策划
*   **目标**：确定产品定位、用户角色及核心激励模型。
*   **决策**：采用“家长版”先行，引入“幻想风格英雄”视觉资产，坚持“以练促学”路径。
*   **产物**：`产品需求文档_PRD_v1.0.md` ✅

### 2. 技术验证：在线视频链接抓取 (核心瓶颈突破)
*   **尝试 1 (yt-dlp/you-get)**：❌ **失败**。触发 B 站 HTTP 412 反爬，识别为爬虫。
*   **尝试 2 (Cookie 提取)**：❌ **失败**。受 Windows DPAPI 安全机制限制，无法直接解密浏览器凭证。
*   **最终方案 (自研 downloader.py)**：✅ **成功**。直接请求底层 API 接口，模拟 HTML5 播放器请求，成功抓取视频。

### 3. 环境适配与引擎优化 (失败与修复)
*   **OCR 初始化报错**：❌ **失败**。PaddleOCR 升级导致 `use_mkldnn` 参数不兼容。
    *   **修复**：✅ **成功**。修改 `video_to_word.py` 移除不兼容参数，通过环境变量强控稳定性。
*   **Flask 启动报错**：❌ **失败**。使用了过时的 `render_to_response`。
    *   **修复**：✅ **成功**。修正为 `render_template`。
*   **前端布局崩溃**：❌ **失败**。HTML 标签嵌套错误导致学生界面消失（掉落至底部）。
    *   **修复**：✅ **成功**。重构 `index.html` 布局，锁定了 50%:50% 的分屏比例。

### 4. 核心功能点达成 (成功记录)
*   **AI 深度出题**：✅ **成功**。针对小学英语视频生成 27 道高质量考题，支持 ASR 语义自动纠错。
*   **虚拟英雄系统**：✅ **成功**。纯代码 (SVG) 生成“音律者 · 琦”与“逻辑刃 · 繁”，支持战力升级与觉醒。
*   **智能视频回溯**：✅ **成功**。答错时精准询问并自动跳转至视频章节对应的时间戳。
*   **全链路交付闭环**：✅ **成功**。实现讲义在线预览及真实 Word 教案文件一键下载。
