# 📘 “微课成才”小程序 PRD v1.0 (Demo版)

## 1. 产品定位
针对中小学学习场景，将短视频/录制视频一键转化为“图文讲义+互动题库”，并通过游戏化机制驱动孩子主动复习，让家长省心辅导。

## 2. 核心用户角色
*   **家长（管理端）**：负责视频源输入、内容安全审核、查看学习报告、分发任务。
*   **学生（学习端）**：负责完成任务、赚取积分、升级虚拟角色、消灭错题。

## 3. 核心功能模块 (MVP 范围)

### 3.1 视频智能转换引擎
*   **双源输入**：支持粘贴抖音/B站链接，或直接上传手机本地视频。
*   **AI 自动化流水线**：
    *   **音轨转录**：提取视频语音并结构化。
    *   **关键画面提取**：智能识别 PPT/黑板翻页。
    *   **内容结构化**：生成带有时间戳的图文讲义。
    *   **智能出题**：根据视频内容生成单选、多选、判断题。

### 3.2 家长审核与分发 (B端模式)
*   **安全快审**：家长预览 AI 生成的讲义和题目，确认无违规内容后，一键点击“发给孩子”。
*   **任务分发**：支持跨设备发送，孩子在自己的微信/平板上接收任务提醒。

### 3.3 游戏化学生端 (C端模式)
*   **身份晋升体系**：高度模拟《王者荣耀》段位（从青铜到最强王者）。
*   **虚拟形象（视觉资产）**：每个学生拥有一个可成长的虚拟人物，通过学习赚取“战力值”来解锁服装、饰品和武器。
*   **交互学习**：路径为“以练促学”。答题错误时，系统自动弹出视频对应片段进行回看。

### 3.4 错题库与遗忘曲线复习
*   **错题溯源**：错题库存储上限随等级提升（Demo版暂定 50 道）。
*   **主动提醒**：根据遗忘曲线，通过微信订阅消息定时提醒家长/学生回来“消灭错题”。
*   **经验奖励**：准时复习错题可获得“暴击经验”和稀有饰品奖励。

### 3.5 家长端报告
*   **周报系统**：汇总孩子本周的学习时长、正确率、知识点分布及战力提升情况。

## 4. 商业与留存逻辑
*   **获取门槛**：视频广告试用。
*   **用户筛选**：后续版本引入订阅制。
*   **用户增长**：高度游戏化的任务奖励模式（打卡/分享）。

---

## 5. Demo 验证目标
1.  验证解析抖音/B站视频链接的稳定性。
2.  验证 AI 生成中小学题目（特别是结合视频内容）的准确度。
3.  验证家长发任务、学生接任务、错题回传的链路通顺性。
