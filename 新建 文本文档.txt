《视频知识自动化生产系统》开发计划书

  一、 项目定位
  将本地视频库自动化转化为：图文教材 (Word/PDF) + 结构化考题 + 同步字幕
  (SRT)。支持无人值守批量作业，具备强大的断点恢复能力，并最终交付给非技术人员直接使用。

  ---

  二、 开发阶段规划

  根据紧迫程度，我们将开发分为三个阶段：

  阶段 1：底座强化（最紧急）
  核心目标：实现无人值守的批量生产，彻底解决程序崩溃后的重复劳动问题。

   * 1.1 批量处理模式 (Batch Mode)
       * 输入流重构：支持扫描指定文件夹下的所有 .mp4, .mkv, .avi 文件。
       * 队列管理：建立处理队列，按顺序自动切换任务，并将结果输出到以视频名命名的独立子文件夹中。
       * 状态看板：在控制台实时显示当前进度（例如：[3/10] 正在处理视频 B...）。

   * 1.2 增强型断点续传与缓存逻辑
       * 精细化缓存校验：不仅检查文件是否存在，还检查文件大小和完整性。
       * 元数据记录
         (task_status.json)：在每个任务文件夹记录每一步的状态（SUCCESS/FAIL/RUNNING），即使电脑断电重启，重新运行程序也
         会从上次失败的精确位置（如：AI生成第3章时出错）继续。
       * 清理机制：提供可选参数，允许在任务完全成功后自动清理中间生成的图片（Frames）以节省磁盘空间。

  阶段 2：功能补完与交付优化
  核心目标：增加核心交付物，提升工具的通用性。

   * 2.1 字幕文件 (SRT) 生成
       * 时间戳对齐：提取 faster-whisper 转录时的原始时间戳数据。
       * 标准格式化：生成标准的 .srt 文件，确保视频播放器可以直接挂载显示。

   * 2.2 轻量化 UI 界面 (Gooey/Streamlit)
       * 参数可视化：将 API Key、视频路径、截图频率、题量要求等硬编码参数移至界面配置项。
       * “傻瓜式”操作：非技术人员只需选择文件夹 -> 点击“开始处理” -> 等待进度条走完。
       * 实时日志展示：在界面上显示当前正在处理的步骤，避免用户以为程序卡死。

  阶段 3：深度智能化与性能优化
  核心目标：精雕细琢，使产品具备竞争优势。

   * 3.1 智能截图与图文精准匹配
       * OCR 辅助截图：利用 OCR 识别画面文字变化，只保留有实质性内容更新的帧（如 PPT 翻页）。
       * 语义锚点技术：AI 整理文稿时，自动标记出最适合插图的位置，实现“文在图旁，图随文走”。
   * 3.2 PDF 完美排版导出
       * 样式自定义：支持设置页眉页脚、字体大小、公司 Logo 等。
       * PDF 直出：无需手动另存为，程序自动完成 Word 转 PDF。
   * 3.3 硬件自适应加速
       * 自动识别电脑是否有 NVIDIA 显卡，动态切换 CPU/GPU 转录模式。

  ---

  三、 技术架构概览

   * 逻辑层: Python 3.11
   * 核心组件:
       * 语音引擎: faster-whisper (Small 模型, Local)
       * 多媒体处理: FFmpeg
       * 逻辑大脑: 阿里百炼 API (Qwen-Max/Plus)
       * 文档引擎: python-docx
       * 界面引擎: Gooey (可将命令行自动转为 GUI) 或 PyQt6
