# “微课成才”小程序 - 虚拟英雄视觉资产生成计划 (Phase 2)

## 1. 目标与定位
基于用户授权的真人形象（宋雨琦、喻繁），不依赖外部公共占位图，直接由 AI 模型生成高品质的“幻想风格”虚拟守护英雄，并将其无缝集成到当前的 Demo 流水线中。

## 2. 核心技术策略：纯代码矢量生成 (SVG/CSS)
为了在不依赖外部图片服务器的前提下实现“一步到位”的高清立绘，我们将采用 **“程序化生成矢量艺术 (SVG)”** 的硬核方式：
模型将直接吐出带有复杂光影、渐变、几何法阵的矢量代码。这不仅保证了 Demo 在任何电脑上都能瞬间加载（零延迟、不破损），还能实现极高帧率的升级动效。

### 2.1 英雄 A：灵动音律者 · 琦 (基于 宋雨琦)
*   **视觉构成**：以紫金、洋红为主色调。
*   **初始形态（见习音律）**：一颗散发着柔和紫色光晕的“音符源石”。
*   **白银骑士形态（音律法师）**：源石展开，呈现出带有环绕五线谱法阵和星芒的华丽形态。

### 2.2 英雄 B：寒霜逻辑刃 · 繁 (基于 喻繁)
*   **视觉构成**：以冰霜蓝、秘银色为主色调。
*   **初始形态（见习剑客）**：一块冷峻、带有几何折线的“六边形剑晶”。
*   **白银骑士形态（寒霜剑士）**：剑晶解体为锋利的剑刃阵列，背景环绕冰蓝色的逻辑脉冲圈。

## 3. 界面重构逻辑 (index.html)
1.  **英雄召唤大厅**：在学生端初始化时，覆盖一层“召唤面板”。展示两位英雄的初始晶体，供学生选择绑定。
2.  **动态头像栏**：将现有的 Emoji 替换为根据选择动态渲染的 SVG 英雄核心。
3.  **大招级晋升动效**：当 27 道题全部答对并提交（或达成通关条件）后，触发 CSS 编写的“源石碎裂 -> 法阵展开”的华丽变身动画。

## 4. 实施步骤
1.  **编写生成代码**：在 `index.html` 注入上述设计的四个 SVG 矢量组。
2.  **编写交互逻辑**：新增英雄选择 JS 函数，记录英雄偏好（`selectedHero = 'qi' | 'fan'`）。
3.  **动效与状态绑定**：将答题得分与英雄的视觉状态（普通 -> 晋升）强绑定。
